# Privacy policy — Zit DataClean

Effective date: 20 October 2026
Publisher: Zit Developer

Zit DataClean processes CSV and Excel files locally on your Windows computer.
The application does not upload your files, contact a server, display ads,
include analytics, or require a user account.

Files are read only after you select or drop them into the application. The
application keeps the imported table in memory while it is open. It writes
cleaned files, optional reports and recipe files only when you request them.
Source files are not overwritten. Temporary files may be written by the Excel
parser/exporter and are cleaned up after normal completion or cancellation;
an abnormal process/system termination can leave temporary files for the OS
to clean up. Windows memory paging and OS-managed crash reporting are outside
the application's control.

The app stores your interface language preference in Windows user settings.
It does not retain your input tables between sessions. Recipe files contain
processing rules and column names, not row data. Reports contain row counts,
rule settings and import warnings, which can include file and worksheet names.
File dialogs and Windows itself may retain recently used folder information.
Copying preview cells uses the Windows clipboard at your request.

Microsoft Store and PayPal have their own policies covering purchases,
licensing, updates and payments. Those services do not receive your table
contents from this application.

For support, use the support link on the official Zit DataClean Store listing
or the issue tracker linked from its project documentation. Do not attach
private files; provide a small redacted example where possible.
